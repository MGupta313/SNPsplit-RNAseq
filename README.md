# How to SNPSplit #

This repo contains scripts to map F1 hybrid samples to N-masked genome, identify reads from each parent and count reads for each parental allele at SNP position.

### Script steps ###

* Mapping - RNAseq.map.snp.split.R
* Counting - getReadCountsforSNP.R
* Histogram - makeHistogram.R
* SNPs in Exons - getSNPsInExons.R
* Gene Level Counting - getReadCountsforGenes.R
* Binomial Test - binomialTest.R
